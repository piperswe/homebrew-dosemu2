# Piperswe Dosemu2

## How do I install these formulae?

`brew install piperswe/dosemu2/<formula>`

Or `brew tap piperswe/dosemu2` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "piperswe/dosemu2"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
